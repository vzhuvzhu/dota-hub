# Dota Hub — локальный сайт с билдами

## Запуск
Двойной клик по `start.bat`: скачает свежие данные и откроет http://localhost:8777.
Можно и без сервера: после `python update.py` просто открой `index.html` в браузере.

## Команды
| Команда | Что делает |
|---|---|
| `python update.py` | обновить игроков, матчи, мейнов и их билды |
| `python update.py --add 76561199802208567` | добавить игрока (Steam64, ID друга или ссылка на профиль) |
| `python update.py --hero Juggernaut --hero 1` | скачать билды доп. героев |
| `python update.py --all-heroes` | билды всех героев (долго, сайт может временно ограничить запросы) |
| `python update.py --fresh` | игнорировать 24-часовой кэш |
| `python update.py --offline` | собрать сайт из кэша, без запросов к D2PT |
| `python update.py --matches 40` | разобрать больше последних матчей (по умолчанию 20) |

## Автообновление
Каждый день в 10:00 Windows запускает `autoupdate.bat` (задача «DotaHub Update»).
Если компьютер был выключен, задача запустится при включении. Лог: `data\autoupdate.log`.
- Другое время: `powershell -ExecutionPolicy Bypass -File install_autoupdate.ps1 -Time 21:00`
- Отключить: `powershell -ExecutionPolicy Bypass -File install_autoupdate.ps1 -Remove`

## Хостинг для друга (GitHub Pages)
Папка `site` уже является git-репозиторием. Чтобы друг открывал сайт по ссылке:
1. Создай на github.com пустой **публичный** репозиторий, например `dota-hub` (на бесплатном плане Pages работает только с публичными).
2. В папке `site`: `git remote add origin https://github.com/<ник>/dota-hub.git`, затем `publish.bat`.
3. В репозитории: Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет на `https://<ник>.github.io/dota-hub/`.

После этого автообновление само публикует свежие данные. Учти: на сайте видны ники, аватары и матчи обоих игроков.
Избранное и заметки хранятся в браузере каждого, у друга будут свои.

## Настройки (`config.json`)
- `players`: список игроков (`account_id`, подпись `label`)
- `main_heroes_count`: сколько мейнов показывать
- `history_days`: за какой период считать мейнов
- `min_position_share`: с какой долей позиции качать отдельный билд (0.15 = 15%)
- `extra_heroes`: герои, добавленные вручную по каждому игроку (если история скрыта)
- `analyze_matches`: сколько последних матчей разбирать подробно
- `parse_requests_per_run`: сколько реплеев за запуск отправлять OpenDota на разбор

## Если чего-то не хватает
- **Нет героев игрока / совместных игр**: в Dota 2 Настройки → Социальное → включить «Общедоступная история матчей». Через несколько часов OpenDota подтянет историю.
- **Нет таймингов и графика золота в матче**: реплей ещё не разобран. Скрипт сам просит OpenDota разобрать его, данные появятся при следующем запуске.
- **У героя нет билда**: `python update.py --hero <имя>`.

## Откуда данные
- Билды, нейтралки, таланты, матчапы: внутреннее JSON API dota2protracker.com (неофициальное, может измениться)
- Профили, матчи, разбор реплеев, патчноуты: OpenDota API
- Картинки: Steam CDN, хранятся в `img/`
